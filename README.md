# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, understand customer preferences, and generate meaningful business insights using Python, SQL, and Power BI.

The objective is to transform raw customer shopping data into actionable insights that can help businesses understand their customers, evaluate purchasing trends, and make data-driven decisions.

## Tools & Technologies

- **Python:** Data cleaning, preprocessing, exploratory data analysis, and data transformation.
- **Pandas & NumPy:** Data manipulation and analysis.
- **SQL (MySQL):** Data querying, business analysis, aggregations, and customer segmentation.
- **Power BI:** Interactive dashboard development and data visualization.
- **Jupyter Notebook:** Python-based analysis and documentation.
- **Git & GitHub:** Project version control and documentation.

## Project Workflow

The project follows an end-to-end data analytics workflow:

1. **Data Loading and Exploration**
   - Imported the raw customer shopping dataset.
   - Examined the dataset structure, columns, data types, and dimensions.
   - Explored initial patterns and identified data quality issues.

2. **Data Cleaning and Preparation (Python)**
   - Handled missing and inconsistent values.
   - Checked for duplicate records.
   - Corrected data types and prepared columns for analysis.
   - Created additional analytical features where required.

3. **Data Analysis (SQL)**
   - Loaded the prepared dataset into a MySQL database.
   - Used SQL queries to analyze customer purchasing behavior.
   - Examined customer segments, product preferences, and purchase patterns.
   - Applied aggregations and analytical queries to answer business questions.

4. **Dashboard Development (Power BI)**
   - Connected the prepared data to Power BI.
   - Developed interactive visualizations and KPI cards.
   - Presented important business metrics and customer behavior patterns.
   - Used filters and slicers to support interactive exploration.

5. **Insights and Reporting**
   - Interpreted the analytical findings.
   - Identified relevant patterns and trends.
   - Summarized findings and potential business recommendations.
